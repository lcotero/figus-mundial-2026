# Figus Mundial 2026

App React para administrar un album de figuritas del Mundial 2026 usando Google Sheets como fuente confiable y cache local del navegador.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Create `.env.local` with:
   `VITE_GOOGLE_CLIENT_ID="YOUR_GOOGLE_OAUTH_WEB_CLIENT_ID.apps.googleusercontent.com"`
3. Run the app:
   `npm run dev`
